# Універсальний Telegram-бот для завантаження медіа (USaver)

Цей Telegram-бот дозволяє легко та швидко завантажувати медіафайли з найпопулярніших платформ безпосередньо у ваш чат. 

## 🚀 Можливості

### 🎥 Відео та Фото
* **TikTok**: Завантаження відео без водяного знаку.
* **TikTok Слайдшоу**: Завантаження всіх фотографій з каруселі.
* **YouTube, Instagram (Reels), Twitter (X)** та інші: Завантаження відео у найкращій доступній якості.
* **Подвійне завантаження (TikTok)**: Разом з TikTok-відео бот автоматично надсилає окремий MP3-файл з музикою з цього відео.

### 🎵 Музика
* **Spotify, SoundCloud, YouTube Music**: Підтримка завантаження музичних треків. Бот автоматично знаходить пісню за лінком, завантажує її в MP3, підтягує правильну назву, виконавця та вбудовує обкладинку (thumbnail), яка ідеально відображається в плеєрі Telegram (до 320x320 px).

### 🛠 Інші функції
* **Статус "Пише..."**: Під час обробки запиту бот показує статус `typing`, щоб користувач розумів, що процес іде.
* **Авто-оновлення**: Бот автоматично робить `git pull` та перезапускається щодня о 3:00 ночі (за Київським часом).
* **Ping-сервер**: Вбудований фіктивний HTTP-сервер для підтримки активності на хостингах типу Render.

## ⚙️ Встановлення та запуск

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/em6race/tg-video-saver.git
   cd tg-video-saver
   ```

2. **Встановіть залежності:**
   Для коректної роботи бота необхідні `yt-dlp`, `python-telegram-bot`, `aiohttp`, `Pillow` та інші бібліотеки.
   ```bash
   pip install -r requirements.txt
   ```
   *Примітка: для роботи `yt-dlp` у системі також повинен бути встановлений [FFmpeg](https://ffmpeg.org/download.html).*

3. **Налаштуйте змінні середовища:**
   Створіть файл `.env` у кореневій папці та додайте наступні параметри:
   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   ADMIN_ID=ваш_telegram_id (для доступу до команди /restart)
   ```

4. **Запустіть бота:**
   ```bash
   python bot.py
   ```

## 📝 Використання
Просто надішліть боту посилання на відео або трек. Бот автоматично розпізнає платформу і надішле вам готовий файл. Для перегляду детального списку можливостей у боті використовуйте команду `/help`.
