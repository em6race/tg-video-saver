# 🤖 USaver — Приватний Telegram-бот для медіа та моніторингу тривог

Приватний Telegram-бот із двома головними напрямками:
1. **Завантаження медіа** — відео, аудіо, слайдшоу з популярних платформ
2. **Моніторинг повітряних тривог** — реалтайм сповіщення через [NEPTUN API](https://neptun.in.ua/)

> ⛔ **Приватний доступ:** бот працює лише для запрошених користувачів. Доступ надається через одноразові посилання-запрошення (`/invite`).

---

## 🚀 Можливості

### 📥 Завантаження медіа

| Платформа | Що підтримується |
|---|---|
| **TikTok** | Відео без водяного знаку + окремий MP3 з відео |
| **TikTok Слайдшоу** | Всі фото з каруселі + аудіо |
| **YouTube** | Відео 🎬, аудіо 🎵 або обидва формати — на вибір |

- 💾 **Кешування:** повторні запити за тим самим посиланням відправляються миттєво (Telegram `file_id`)
- ⌨️ **Статус «Пише...»:** відображається під час обробки

### 🚨 Моніторинг повітряних тривог (NEPTUN API)

Система відстежує повітряний простір у реальному часі та надсилає персональні сповіщення.

#### Рівні небезпеки
- 🔴 **Червоний** — ракетна небезпека, шахеди, балістика (потрібно в укриття)
- 🟡 **Жовтий** — загроза артобстрілу, дрони на підльоті до кордону
- 🟢 **Відбій** — повідомлення автоматично оновлюється (тихо, без звуку)

#### Одне «живе» повідомлення внизу чату — без спаму
Бот підтримує статусне повідомлення завжди в кінці чату та не спамить новими повідомленнями.
| Подія | Дія бота |
|---|---|
| 🟢 → 🔴/🟡 Нова тривога | Автоматично репостить **нове** актуальне повідомлення зі звуком у сам кінець чату |
| 🔴 ↔ 🟡 Зміна рівня | **Видаляє** старе повідомлення та надсилає оновлене в кінець чату |
| 🔴/🟡 → 🟢 Відбій | **Пересилає/редагує** статус відбою у кінець чату |
| Кнопка «🔄 Оновити» | Видаляє натиснуте повідомлення та пересилає новий статус в кінець чату |

#### 🎯 Вектори руху цілей, достовірність та попередження
- 🧭 **Курс та напрямок:** Для зафіксованих цілей відображається азимут та напрямок руху (наприклад: `курс ↓ Південь`).
- 🛡️ **Достовірність цілі:** Для кожної цілі з виділеного API виводиться рівень достовірності (`Висока`, `Середня`, `Низька`, `Непідтверджена`).
- ⚠️ **Попередження про безпосередню небезпеку:**
  - Спрацьовує **тільки якщо ціль знаходиться на відстані ≤ 20 км** від вашої геопозиції ТА вектор її руху спрямований безпосередньо на вас (кут ≤ 45°).
  - Повідомлення показується **один раз внизу списку цілей** із зазначенням exact кількості небезпечних цілей.

#### Встановлення локації та зручна навігація
- 📍 **GPS-кнопка** — надсилає мої GPS-координати для точного прив'язування
- ⌨️ **Текстовий пошук** — пошук населеного пункту за назвою (`Ірпінь`, `Одеса`) з кешуванням Nominatim
- 🗺️ **Вручну зі списку** — 24 області України через інлайн-меню
- 🧹 **Чистий інтерфейс** — автоматичне видалення команд юзера та тимчасових повідомлень меню

#### Карта тривог (`/map`)
Генерує HD-зображення карти України:
- 🔴🟡 Кольорове підсвічування областей та районів
- 🛸 Повітряні цілі зі стрілками напрямку польоту
- 📍 Ваша геопозиція позначена на карті
- ❌ **Кнопка «Закрити карту»** — видаляє зображення карти, залишаючи актуальний картку-статус

### 🔒 Система приватного доступу

- **`/invite`** — генерує одноразове посилання з терміном дії **30 хвилин** (лише для адміна)
  - Синє клікабельне гіперпосилання + кнопки «Відкрити» та «Поділитись»
  - Захист від спалювання: якщо адмін сам клікне — посилання не згорить
- **`/invite clear`** або **`/clear_invites`** — видалити всі невикористані запрошення
- **`/users`** — список всіх авторизованих користувачів

---

### 🛠 Технічні особливості

- **Модульна архітектура:** розділені обробники у `handlers/` та внутрішні сервіси у `services/`.
- **Асинхронна БД (`aiosqlite`):** високопродуктивна робота з SQLite без блокування event loop.
- **Типізація даних (`@dataclass`):** моделі `ThreatItem` та `AlertStateData` для безпечної обробки API NEPTUN.
- **Централізований Error Handler:** автоматичне логування та обробка винятків.
- **Ping-сервер:** вбудований HTTP-сервер для хостингів типу Render/Koyeb.
- **`/restart`** — ручний перезапуск (адмін).

## ⚙️ Встановлення та запуск

### 1. Клонуйте репозиторій
```bash
git clone https://github.com/em6race/tg-video-saver.git
cd tg-video-saver
```

### 2. Встановіть залежності
```bash
pip install -r requirements.txt
```
> ⚠️ Для роботи `yt-dlp` потрібен [FFmpeg](https://ffmpeg.org/download.html)

### 3. Створіть файл `.env`
```env
BOT_TOKEN=ваш_токен_від_BotFather
ADMIN_ID=ваш_telegram_id
PORT=8080
```

### 4. Запустіть
```bash
python bot.py
```

## 📁 Структура проєкту

```
tg-video-saver/
├── bot.py              # Головний бот (медіа + тривоги)
├── database.py         # Асинхронна БД SQLite (aiosqlite)
├── neptun_alerts.py    # NEPTUN API, dataclasses, кеш геокодингу, рендер карт
├── keyboards.py        # Інлайн та Reply клавіатури
├── handlers/           # Обробники команд та повідомлень
│   ├── admin.py        # Адмін-команди (/start, /invite, /users, /restart)
│   ├── alerts/         # Модульний пакет тривог (location, monitoring, commands, callbacks)
│   ├── common.py       # Перевірка доступу, error_handler, /help, /myid
│   └── media.py        # Завантаження медіа (TikTok, YouTube, Spotify)
├── services/           # Завантажувачі та внутрішні сервіси
│   ├── downloader.py   # yt-dlp завантаження
│   ├── spotify_api.py  # Spotify API метадані
│   ├── tiktok_api.py   # TikTok / TikWM API
│   └── server.py       # HTTP keep-alive сервер
├── tests/              # Тестові та діагностичні скрипти
├── requirements.txt    # Залежності Python
└── .env.example        # Приклад конфігурації
```
