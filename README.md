Сучасний високопродуктивний багатофункціональний Telegram-бот нового покоління для персональної безпеки та медіа-потреб:
1. 🚨 **Моніторинг повітряних загроз у реальному часі** — інтеграція з мережею [NEPTUN API](https://neptun.in.ua/) (дані Повітряних Сил ЗСУ та моніторингових систем).
2. 📥 **Модульний медіа-завантажувач** — завантаження відео, слайдшоу та музики без водяних знаків із популярних сервісів.
3. 🎟️ **Гнучкий контроль доступу** — конструктор одноразових та багаторазових інвайтів з автовидаленням.

## 🌟 Ключові можливості

### 🚨 1. Система моніторингу повітряного простору (NEPTUN Engine)

* 📍 **Точне позиціонування:**
  * Швидке надсилання GPS-координат однією кнопкою.
  * Текстовий геопошук міст, смт і сіл по всій Україні з кешуванням Nominatim.
  * Ручний вибір із 24 областей та районів України.
* 🎯 **Розумні вектори цілей:**
  * Розрахунок реальної відстані до об'єкта в кілометрах (`~14.5 км`).
  * Визначення курсу та азимуту польоту (стрілки та сторони світу).
  * **Алгоритм прямої небезпеки:** якщо ціль наближається безпосередньо до вашої локації (відстань ≤ 20 км, курс під кутом ≤ 45°) — бот видає помітне попередження: `⚠️ у ваш бік!`.
* 🏷️ **Статус-бейджи цілей у реальному часі:**
  * 🎯 `[ЗБИТО]` — перехоплення та знищення ворожої цілі.
  * ⚠️ ⬇️ `[ПАДАЄ / ЗНИЖУЄТЬСЯ]` — критичне сповіщення про втрату висоти або падіння підбитого дрона.
  * 💨 `[ЛОКАЦІЙНО ВТРАЧЕНО]` — коли дрон зник з радарів або подавлений засобами РЕБ.
  * 💥 `[ВИБУХ / ДЕТОНАЦІЯ]` — фіксація звуків вибухів / прильотів.
  * ⚡ `[РОБОТА ППО]` — робота мобільних вогневих груп або ЗРК.
* 🎨 **Кастомні емодзі Повітряних Сил:**
  * Повна інтеграція з паками `@monitorwarr` та `PS_WAR_NEW` (шахеди, крилаті ракети, балістика, КАБи, літаки Су-34/МіГ-31К, радари, шеврони ПвК).
  * 100% безпечний fallback: якщо на акаунті немає Premium, повідомлення акуратно відображаються якісними Unicode-емодзі.
* 🗺️ **Інтерактивна HD-карта тривог (`/map`):**
  * Графічний рендер мапи України з колірним підсвічуванням тривог (червоний/жовтий/зелений).
  * Відображення повітряних цілей зі стрілками курсу та персональною міткою користувача на карті.
* 🧹 **Чистий чат без спаму («Жива картка»):**
  * Повідомлення тривоги постійно тримається в самому низу чату.
  * При зміні обстановки чи відбої попередні картки видаляються або оновлюються на місці без накопичення сотень сповіщень.
* 🔔 **Гнучкий контроль звуку:**
  * Перемикання беззвучного / звукового режиму прямо з картки тривоги. Відбій тривоги завжди приходить тихо, не турбуючи вночі.

### 📥 2. Модульний мультимедійний модуль (Медіа-комбайн)

Модуль можна активувати або вимкнути однією змінною в `.env` (`ENABLE_MEDIA_PLUGIN=true/false`). При вимкненому плагіні бот працює як ультралегкий моніторинг тривог (споживання лише **~38 МБ RAM**).

| Платформа | Можливості завантаження |
|---|---|
| **TikTok** | Відео без водяних знаків + окремий MP3-аудіотрек |
| **TikTok Фото** | Повне слайдшоу: всі фотографії з каруселі в оригінальній якості + фоновий трек |
| **YouTube / Shorts** | Інтерактивний вибір: 🎬 Відео, 🎵 Аудіо або обидва варіанти одночасно |
| **Instagram Reels** | Відео у високій роздільній здатності |
| **Spotify** | Повноцінний MP3 з метаданими: виконавець, назва пісні та оригінальна обкладинка |
| **SoundCloud** | Високоякісні MP3-треки |
| **Twitter / X** | Відеофайли з постів |

* ⚡ **Розумний кеш (SQLite):** повторні запити однакових посилань відправляються миттєво через збережений `file_id`.
* ⏳ **Анімація обробки:** відображення статусів «Завантажую...» та Telegram Typing-action.

### 🎟️ 3. Приватний доступ та адміністрування

* 🎫 **Візуальний конструктор інвайтів:**
  * Налаштування ліміту використань: 1, 2, 3, 5, 10 або безліміт.
  * Налаштування терміну дії: 30 хв, 1 год, 6 год, 24 год, 7 днів або безстроково.
* 🗑️ **Автоочищення повідомлень:** коли всі використання вичерпано — повідомлення із запрошенням автоматично видаляється з чату адміна.
* 📋 **Керування запрошеннями (`/invites`):** перегляд списку активних кодів з можливістю анулювання в один клік.
* 👥 **Керування користувачами (`/users`):** список усіх підписників бота з інформацією про підключене місто та кнопкою негайного блокування.
* 🔄 **Безперервне оновлення (`/restart`):** підтягування свіжого коду з GitHub `main` без переривання сервісу + автоматичне оновлення щоночі о 03:00.

## 🛠 Технічний стек

* **Мова:** Python 3.11+
* **Фреймворк:** `python-telegram-bot` (v21+ Async/Await)
* **Мережа та API:** `aiohttp`, `httpx`, `pytz`
* **База даних:** `aiosqlite` (повністю асинхронний драйвер SQLite)
* **Графіка:** Pillow (`PIL`) для генерації карт та кастомних зображень
* **Завантажувачі:** `yt-dlp` з оптимізацією CPU та контролем потоків FFmpeg

## 🚀 Встановлення та розгортання

### 1. Клонування репозиторію
```bash
git clone https://github.com/em6race/tg-video-saver.git
cd tg-video-saver
```

### 2. Створення віртуального оточення
```bash
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
# або: venv\Scripts\activate на Windows
pip install -r requirements.txt
```

### 3. Налаштування змінних оточення (`.env`)
Створіть файл `.env` на основі шаблону `.env.example`:
```env
# Токен вашого Telegram бота (отримати у @BotFather)
BOT_TOKEN=your_telegram_bot_token_here

# Telegram User ID адміністратора бота (отримати через команду /myid в боті)
ADMIN_ID=123456789

# ========================================================
# Гнучке керування модулями (true / false)
# Обидва модулі за замовчуванням увімкнені (true).
# Якщо вам потрібен суто скачувальник — вимкніть тривоги (ENABLE_ALERTS_PLUGIN=false).
# Якщо вам потрібен суто моніторинг тривог — вимкніть медіа (ENABLE_MEDIA_PLUGIN=false).
# ========================================================

# 1. Завантаження відео та музики (TikTok, YouTube, Instagram, Spotify, SoundCloud)
ENABLE_MEDIA_PLUGIN=true

# 2. Моніторинг повітряних тривог та радар загроз (NEPTUN API)
ENABLE_ALERTS_PLUGIN=true

# Порт для веб-сервера (якщо потрібен для хостингу Render/Railway/Koyeb)
PORT=8080
```

| Змінна | Опис | Обов'язкова |
|---|---|---|
| `BOT_TOKEN` | Токен бота, отриманий у [@BotFather](https://t.me/BotFather) | Так |
| `ADMIN_ID` | Ваш числовий Telegram User ID (для доступу до адмін-панелі) | Так |
| `ENABLE_MEDIA_PLUGIN` | `true` — увімкнути завантажувач медіа; `false` — вимкнути для економії CPU/RAM (~38 МБ) | Ні (за замовчуванням `true`) |
| `ENABLE_ALERTS_PLUGIN` | `true` — увімкнути моніторинг тривог; `false` — вимкнути (режим суто завантажувача) | Ні (за замовчуванням `true`) |
| `PORT` | Порт HTTP-сервера для хмарних сервісів із health-check (Render/Koyeb) | Ні (за замовчуванням `8080`) |

### 4. Запуск бота
```bash
python bot.py
```

### 5. Автозапуск через Systemd (Linux / VPS)
Для роботи у фоновому режимі 24/7 створіть сервіс:
```ini
# /etc/systemd/system/tg-alerts-bot.service
[Unit]
Description=Telegram Air Raid Alerts & Media Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/tg-alerts-bot
ExecStart=/home/ubuntu/tg-alerts-bot/venv/bin/python /home/ubuntu/tg-alerts-bot/bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now tg-alerts-bot
```

## 📋 Список команд

### 👤 Користувацькі команди
| Команда | Опис |
|---|---|
| `/start` | Авторизація за інвайтом або запуск головного меню |
| `/status` | Перевірити статус тривоги та цілей у радіусі міста |
| `/map` | Надіслати актуальну графічну карту тривог України |
| `/alerts` | Меню налаштування локації (GPS, місто, область, звук) |
| `/help` | Детальна довідка по користуванню ботом |

### 👑 Команди адміністратора
| Команда | Опис |
|---|---|
| `/invite` | Відкрити інтерактивний конструктор запрошень |
| `/invites` | Список активних запрошень з можливістю скасування |
| `/clear_invites` | Анулювати всі невикористані запрошення |
| `/users` | Список авторизованих користувачів та керування доступом |
| `/restart` | Оновити код із GitHub (`git pull`) та перезапустити бота |

## 📁 Архітектура проєкту

```
tg-alerts-bot/
├── bot.py                  # Головна точка входу, ініціалізація та реєстрація обробників
├── database.py             # Асинхронний шар бази даних SQLite (aiosqlite)
├── keyboards.py            # Інлайн- та Reply-клавіатури для меню
├── requirements.txt        # Список залежностей Python
├── .env.example            # Зразок файлу конфігурації
├── handlers/               # Модульні обробники подій Telegram
│   ├── admin.py            # Конструктор інвайтів, керування користувачами, /restart
│   ├── common.py           # Авторизація, перевірка доступу, глобальний error handler
│   ├── media.py            # Обробка посилань на відео та музику (TikTok, YouTube, Spotify)
│   └── alerts/             # Логіка повітряних тривог
│       ├── commands.py     # Команди /status, /map, /alerts, ручне оновлення
│       ├── callbacks.py    # Обробка інлайн-кнопок вибору областей та звуку
│       ├── location.py     # GPS-геолокація та зворотний геокодинг
│       ├── monitoring.py   # Фоновий цикл опитування NEPTUN API та розсилка карток
│       └── state.py        # Кеш станів тривог та сигнатур небезпеки
├── neptun_alerts/          # Пакет роботи з даними моніторингу
│   ├── api.py              # Клієнт REST API NEPTUN (/alerts та /threats)
│   ├── evaluator.py        # Оцінка загроз, розрахунок дистанцій, курсів і кутів
│   ├── formatter.py        # HTML-форматування карток тривог, кастомні емодзі та статус-бейджи
│   ├── geocoding.py        # Геокодинг міст через Nominatim з локальним кешем
│   ├── map.py              # Рендеринг зображення карти тривог із GeoJSON
│   └── models.py           # Dataclass-моделі структури даних
└── services/               # Сервіси завантаження контенту
    ├── downloader.py       # Завантаження та конвертація через yt-dlp
    ├── spotify_api.py      # Робота з API метаданих Spotify
    └── tiktok_api.py       # API обробки відео та слайдшоу TikTok
```
